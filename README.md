# ToDoList (C# Windows Forms)

Tapşırıqlar üçün sadə ToDoList — textBox ilə məlumat, DataGridView ilə siyahı, CheckBox ilə sildir.

## Funksiyalar
- Acildi hezle iki misal tapshiriq.
- Button1: yeni tapshiriq elave et, boş ad xəbərdarlığı.
- CheckBox sutunu: "Bu tapşırığı silmək istəyirsiniz?" suali, Yes-də sile.
